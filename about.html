About

An interactive Game of Life that runs entirely in your browser.

Game of Life

The British mathematician John Horton Conway devised the Game of Life in 1970. It became widely known after Martin Gardner described it in Scientific American that October. From a handful of rules, patterns appear that move, repeat, collide and grow, which is why it has fascinated people for decades.

Conway's Game of Life on Wikipedia

About this project

Draw your own patterns, change the rules, resize the grid and watch the generations unfold. Everything runs locally in your browser, so there is nothing to install and no account to create.

Made by Jinseok Jung. The source code is on GitHub.

Built with

  • Python, running in the browser through Pyodide (Python compiled to WebAssembly).
  • Tailwind CSS for the styling.
  • JavaScript and an HTML canvas for drawing.

Resources
